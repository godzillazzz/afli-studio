# Afli Studio — คู่มือการใช้งาน

ส่งลิงก์สินค้า Shopee ผ่านหน้าเว็บบนมือถือ แล้วระบบจะเขียนสคริปต์ พากย์เสียงไทย ใส่ซับไตเติล ตัดต่อเป็นคลิปแนวตั้ง 9:16 และโพสต์ลง Facebook / ส่งเข้า TikTok ให้อัตโนมัติ

---

## 1. ติดตั้ง (ทำครั้งเดียว ประมาณ 10 นาที)

บนเซิร์ฟเวอร์ Debian:

```bash
git clone https://github.com/godzillazzz/afli-studio.git && cd afli-studio && sudo bash install.sh
```

ถ้าเครื่องไม่มีคำสั่ง git ให้ใช้คำสั่งนี้แทน:

```bash
curl -L https://github.com/godzillazzz/afli-studio/archive/refs/heads/main.tar.gz | tar xz && cd afli-studio-main && sudo bash install.sh
```

**อัปเดตเป็นเวอร์ชันใหม่:** `cd afli-studio && git pull && sudo bash install.sh`

ตัวติดตั้งจะลง Docker ให้เอง ถามรหัสผ่าน แล้วแสดงที่อยู่เว็บ เช่น `http://192.168.23.94:8088`

> ระบบรันแยกใน Docker คนละพอร์ตกับระบบเดิม ไม่ยุ่งกับฐานข้อมูลหรือระบบอื่นในเครื่อง

**อัปเดตหรือรีสตาร์ต:** รัน `sudo bash install.sh` ซ้ำได้เลย ข้อมูลจะไม่หาย (เก็บอยู่ในโฟลเดอร์ `data/`)

## 2. เปิดบนมือถือ

1. เปิดลิงก์จากข้อ 1 ใน Chrome หรือ Safari แล้วใส่รหัสผ่าน
2. กด **"เพิ่มไปยังหน้าจอหลัก"** (Add to Home Screen) เพื่อให้มีไอคอนเหมือนแอป

**ใช้งานนอกบ้าน (ไม่ได้ต่อ Wi-Fi เดียวกัน)** มี 2 วิธี
- **Tailscale (ง่ายที่สุด ฟรี):** ติดตั้ง Tailscale บนเซิร์ฟเวอร์ (`curl -fsSL https://tailscale.com/install.sh | sh && sudo tailscale up`) และบนมือถือ ล็อกอินบัญชีเดียวกัน แล้วเปิด `http://<ชื่อเครื่องใน Tailscale>:8088`
- **Cloudflare Tunnel (ฟรี ต้องมีโดเมน):** ได้ลิงก์ `https://...` ใช้ได้จากทุกที่ **จำเป็นถ้าจะเชื่อม TikTok แบบอัตโนมัติ** (ข้อ 6)

## 3. วิธีใช้งานประจำวัน

1. คัดลอกลิงก์ affiliate จากแอป Shopee
2. เปิด Afli Studio ➜ กด **📋 วางลิงก์** ➜ เลือกรูปแบบวิดีโอ ➜ กด **🎬 สร้างคลิป**
3. รอ 1–3 นาที ดูความคืบหน้าได้ที่แท็บ **งานทั้งหมด**
4. เมื่อเสร็จ: ดูคลิป ➜ แก้สคริปต์หรือแคปชันได้ ➜ กดโพสต์

| รูปแบบ | ได้อะไร | ค่าใช้จ่ายโดยประมาณ |
|---|---|---|
| 🖼️ สไลด์รูป | รูปสินค้าซูมเคลื่อนไหว + เสียงพากย์ + ซับ | ~0.1–1 บาท |
| ✨ ผสม AI | คลิป AI เปิดเรื่อง 5 วินาที + สไลด์รูป | ~10 บาท |
| 🤖 AI ล้วน | คลิป AI 2 ช่วง + สไลด์รูป | ~20 บาท |

**ถ้าดึงข้อมูลจาก Shopee ไม่ได้** (Shopee บล็อกบอทเป็นบางครั้ง): กด "➕ ใส่ข้อมูลเอง" พิมพ์ชื่อและราคา แล้วอัปโหลดรูปจากมือถือ (แคปหน้าจอรูปสินค้าก็ได้) ใส่คลิปที่ถ่ายเองได้ด้วย ระบบจะนำมาตัดต่อรวมกัน

**เพลงประกอบ:** วางไฟล์ `.mp3` (เพลงที่มีสิทธิ์ใช้งาน หรือเพลงฟรีลิขสิทธิ์) ไว้ในโฟลเดอร์ `data/music/` ระบบจะสุ่มใส่ให้เบาๆ ใต้เสียงพากย์

## 4. ตั้งค่า AI (แท็บ ⚙️ ตั้งค่า)

- **Anthropic API Key** (เขียนสคริปต์): สมัครที่ console.anthropic.com ➜ เติมเงิน $5 ใช้ได้หลายพันคลิป ถ้ายังไม่ใส่ ระบบใช้สคริปต์แม่แบบแทน
- **fal.ai API Key** (วิดีโอ AI): สมัครที่ fal.ai ➜ Billing เติมเงิน ➜ Keys สร้างคีย์ จำเป็นเฉพาะโหมด "ผสม AI" และ "AI ล้วน"
- **เลือก AI สร้างวิดีโอ:** เลือกได้ 2 ตัว ใช้เฉพาะโหมด "ผสม AI" และ "AI ล้วน"

  | ตัวเลือก | ค่าใช้จ่ายต่อคลิป AI | ต้องใช้ |
  |---|---|---|
  | Kling 2.1 (fal.ai) | ~9 บาท (5 วินาที) | fal.ai API Key |
  | Veo 3.1 Lite | ~11 บาท (6 วินาที) | Gemini API Key |
  | Veo 3.1 Fast | ~22 บาท (6 วินาที) | Gemini API Key |
  | Veo 3.1 | ~86 บาท (6 วินาที) | Gemini API Key |

  **วิธีขอ Gemini API Key:** เข้า aistudio.google.com/apikey ➜ Create API key ➜ เปิด Billing ของโปรเจกต์ (Veo ไม่มีโควตาฟรี) ➜ นำคีย์มาใส่ในหน้าตั้งค่า แล้วเลือก "Google Veo 3.1"
  > Veo ผ่าน API คิดเงินแยกจากแพ็กเกจ Google AI ที่ใช้กับ Flow ระบบใช้เครดิต Flow ไม่ได้ ถ้าอยากใช้เครดิต Flow ให้สร้างคลิปใน Flow เอง ดาวน์โหลด แล้วอัปโหลดเข้า Afli Studio ใน "➕ ใส่ข้อมูลเอง" ระบบจะใส่เสียงพากย์ ซับ และโพสต์ให้
- **เสียงพากย์:** เลือกได้ 3 เสียง (ฟรี ไม่ต้องใช้คีย์)

## 5. เชื่อม Facebook Page (โพสต์ Reels อัตโนมัติ)

> โพสต์ได้เฉพาะ **Facebook Page** เพราะ Facebook ไม่อนุญาตให้โปรแกรมโพสต์ลงโปรไฟล์ส่วนตัว และ API จำกัดไว้ที่ 30 Reels ต่อวันต่อเพจ

1. ไปที่ developers.facebook.com ➜ **My Apps ➜ Create App** ➜ เลือกประเภท Business
2. เปิด **Graph API Explorer** ➜ เลือกแอปที่สร้าง ➜ Add permissions: `pages_show_list`, `pages_read_engagement`, `pages_manage_posts` ➜ กด **Generate Access Token** แล้วอนุญาตเพจของคุณ
3. นำ token ไปที่ **Access Token Debugger** ➜ กด **Extend Access Token** (ได้ token ระยะยาว)
4. กลับไปที่ Graph API Explorer ใส่ token ระยะยาว ➜ เรียก `me/accounts` ➜ คัดลอก `id` (Page ID) และ `access_token` ของเพจ
5. ใส่ทั้งสองค่าในหน้าตั้งค่า ➜ บันทึก

## 6. เชื่อม TikTok และการปักตะกร้า

**ทำไมไม่ปักตะกร้าอัตโนมัติ 100%:** TikTok ไม่เปิดให้โปรแกรมภายนอกติดสินค้าในตะกร้า ถ้าใช้บอทกดแทน บัญชีเสี่ยงโดนแบนหรือโดนตัดสิทธิ์ affiliate ระบบจึงทำแบบนี้แทน:

1. ระบบส่งคลิปเข้า **กล่องข้อความในแอป TikTok** ของคุณ (ผ่าน API ทางการ)
2. เปิดแอป TikTok ➜ แตะแจ้งเตือน ➜ กด **เพิ่มลิงก์ ➜ สินค้า** ➜ เลือกสินค้า (ปักตะกร้า) ➜ วางแคปชัน ➜ โพสต์

ใช้เวลาประมาณ 10–20 วินาทีต่อคลิป

**วิธีเชื่อม (ต้องมีลิงก์ https จากข้อ 2):**
1. developers.tiktok.com ➜ สร้างแอป ➜ เพิ่ม **Login Kit** และ **Content Posting API**
2. ตั้ง Redirect URI เป็น `https://<ลิงก์ของคุณ>/api/tiktok/callback`
3. เริ่มจากโหมด **Sandbox** แล้วเพิ่มบัญชี TikTok ของคุณเป็นผู้ใช้ทดสอบ (ถ้าจะใช้ระยะยาว ให้ส่งแอปให้ TikTok ตรวจสอบ)
4. ใส่ Client Key, Client Secret, Public URL ในหน้าตั้งค่า ➜ กด **🔗 เชื่อมบัญชี TikTok**

**ยังไม่อยากตั้งค่า TikTok?** กด **⬇️ ดาวน์โหลด** ในหน้าคลิป ➜ เปิดแอป TikTok ➜ อัปโหลด ➜ ปักตะกร้า ➜ วางแคปชัน (กด 📋 คัดลอกแคปชันไว้ก่อน)

## 7. ข้อควรระวัง

- ใช้รูปหรือคลิปจากหน้าร้านค้า หรือที่ถ่ายเองเท่านั้น ไม่ควรใช้คลิปของครีเอเตอร์คนอื่น เพราะติดลิขสิทธิ์และแพลตฟอร์มจะลดการมองเห็นคลิปซ้ำ
- ตรวจสคริปต์ก่อนโพสต์ โดยเฉพาะสินค้าสุขภาพหรือความงาม เพราะการอ้างสรรพคุณเกินจริงผิดกฎแพลตฟอร์ม
- เสียงพากย์ฟรีใช้บริการของ Microsoft Edge ถ้าวันหนึ่งใช้งานไม่ได้ ให้แจ้ง Claude เพื่อเปลี่ยนไปใช้บริการเสียงแบบเสียเงิน
